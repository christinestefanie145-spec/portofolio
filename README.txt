PORTOFOLIO PERSONAL - TUGAS AKHIR 1 PTI

Cara menjalankan:
1. Ekstrak folder proyek.
2. Buka index.html menggunakan browser atau jalankan Live Server dari VS Code.
3. Koneksi internet diperlukan untuk memuat Bootstrap CDN, Bootstrap Icons, dan Google Fonts.

Sebelum dikumpulkan:
- periksa Nama Lengkap, NIM, fakultas, universitas, domisili, dan seluruh placeholder dengan data asli.
- periksa assets/img/profil.svg dengan foto profil resmi (ubah src di index.html jika nama file berbeda).
- Pastikan tiga proyek pada bagian Proyek benar-benar karya sendiri. deskripsi, teknologi, gambar/pratinjau, dan tautannya.
- Lengkapi riwayat pendidikan/organisasi sesuai pengalaman nyata.
- Uji tampilan pada ponsel, tablet, dan desktop.
- Form kontak memakai mailto, bukan backend/server; alamat penerima perlu diganti.

Struktur:
index.html
css/style.css
js/script.js
assets/img/foto.jpg

Teknologi: HTML5, Bootstrap 5.3, CSS kustom, JavaScript.
